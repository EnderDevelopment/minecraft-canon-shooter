# CanonShooter

CanonShooter is a Minecraft plugin that allows players to create and use a cannon. The cannon is a stick item that, when right-clicked, launches a snowball projectile. This plugin is designed to add a fun and interactive element to Minecraft servers, providing players with a unique way to engage in combat or play.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Obtain a cannon by using the `/givecannon` command.
2. Right-click with the cannon in your hand to launch a snowball projectile.
